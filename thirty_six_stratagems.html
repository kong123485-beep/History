三十六計全文

《三十六計》是中國古代的一部兵法奇書，依據《易經》陰陽變化之理推演而成，共分六套計謀，每套六計，合計三十六計。

第一套 勝戰計（第1-6計）

處於絕對優勢地位時所使用的計謀。

  1. 瞞天過海：防備周密時容易麻痺，常見的事物不再懷疑。
  2. 圍魏救趙：避實擊虛，攻敵必救以解自身之圍。
  3. 借刀殺人：藉助別人的力量去消滅敵人。
  4. 以逸待勞：指困敵之勢，不正面衝突，以己之靜待敵之動。
  5. 趁火打劫：敵方遭遇危機時，乘機出兵奪取勝利。
  6. 聲東擊西：製造假象迷惑敵人，使其方向混亂。

第二套 敵戰計（第7-12計）

勢均力敵、對峙狀態下使用的計謀。

  1. 無中生有：利用假象使敵方誤以為真，真假虛實相生。
  2. 暗度陳倉：正面示人以佯攻，暗地裡奇兵突襲。
  3. 隔岸觀火：敵方內部混亂時靜觀其變，等其兩敗俱傷。
  4. 笑裏藏刀：表面和善友好，暗中積蓄力量準備突襲。
  5. 李代桃僵：勢必有所損失時，犧牲局部以換取全局勝利。
  6. 順手牽羊：微小的漏洞也要利用，乘機獲取利益。

第三套 攻戰計（第13-18計）

攻打或正面交鋒時所使用的計謀。

  1. 打草驚蛇：有懷疑時要先偵察，發現可疑要反覆試探。
  2. 借屍還魂：利用已經消失或無用的名義、力量來為己服務。
  3. 調虎離山：引誘敵人離開有利地形或堅固防線。
  4. 欲擒故縱：故意放鬆對敵人的逼迫，使其鬥志渙散再一舉擒獲。
  5. 拋磚引玉：用類似的假象或微小的代價，引誘敵方暴露出主力或主力意圖。
  6. 擒賊擒王：摧毀敵人的核心主力或首領，使其全軍瓦解。

第四套 混戰計（第19-24計）

局勢混亂、真假難辨時使用的計謀。

  1. 釜底抽薪：不正面抗迎敵人的鋒芒，而是從根本上削弱敵人的力量。
  2. 混水摸魚：乘敵方內部混亂、失去控制時奪取勝利。
  3. 金蟬脫殼：製造完美的假象留在原地，主力已隱蔽轉移。
  4. 關門捉賊：對弱小的敵人要包圍殲滅，不留後路防止其逃跑。
  5. 遠交近攻：與遠處的國家或勢力結盟，先攻打鄰近的敵人。
  6. 假途伐虢：藉口向對方借道，乘機將其消滅。

第五套 并戰計（第25-30計）

與盟友或友軍協同作戰時（或對付盟友）使用的計謀。

  1. 偷梁換柱：暗中頻繁變更敵人的陣容，抽換其主力。
  2. 指桑罵槐：採取間接的警告或懲罰，以震懾和控制部屬或盟友。
  3. 痴人說夢：用假象或虛言欺騙糊塗的敵人。
  4. 上屋抽梯：故意露出破綻引誘敵人深入，隨後切斷其後路。
  5. 樹上開花：借用別人的局面或製造虛假聲勢，使自己顯得強大。
  6. 反客為主：乘隙插足，循序漸進地掌握主導權。

第六套 敗戰計（第31-36計）

處於絕對劣勢、面臨失敗時所使用的計謀。

  1. 美人計：對兵力強大的將領，利用美色與享樂削弱其鬥志。
  2. 空城計：在兵力極度空虛時，故意示人以空虛，使多疑的敵人不敢輕進。
  3. 反間計：利用敵人的間諜向敵方傳遞假情報，使其內部猜忌。
  4. 苦肉計：故意傷害自己以騙取敵人的信任，進行內應。
  5. 連環計：將多個計謀環環相扣，或使敵人兵力相互牽制。
  6. 走為上計：全軍退卻，避開強敵，是保存實力以圖後效的最佳選擇。
